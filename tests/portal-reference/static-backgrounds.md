The separate stock-backgrounds session runs actual GNOME 51 Settings against the
packaged compositor/GTK shell with an ordinary user and shared private keyfile
backend. It selects eight genuine wallpaper-list descriptor items through the
stock chooser's accessible controls: all six picture placements plus horizontal
and vertical gradients with no picture. It never sets the tested keys itself.

Each selection must change the independently observed desktop AND screensaver
metadata, expose the real checked chooser item, and paint specified fixture colors
at several retained screenshot coordinates after Settings exits. The points
separate centered/fit bars, cover crop versus stretching, tiled phase, and gradient
directions. Identity checks pin the stock application's bus owner/PID/UID/start
and installed executable hash. Compositor scenes, accessible trees, key snapshots,
versioned published metadata, actual frames and pixel observations are retained.

A second genuine compositor/GTK shell session then consumes the persisted final
selection. Both original process identities must have changed, with identical
candidate GTK executable bytes; pixels are checked BEFORE relaunching Settings,
then its persisted selected item is checked. Multi-output span/tile geometry has
additional pure renderer tests; the one-output nested journey is not physical
multi-monitor qualification. Full standard native VM/security checks remain
mandatory, and dynamic XML/time/monitor-variant/physical/final-image acceptance
remains open under #360.

The private wallpaper drop preserves the original four lines and appends one
bounded version-1 JSON metadata record with separate typed desktop/lock placement,
shading and primary/secondary colors. New publishers always emit this record;
invalid, unknown-version, unknown-field or extra-line metadata is rejected rather
than interpreted as legacy zoom. Memory/worker/card/lock/disk identities include
settings, actual output geometry and opened source-file identity. Image reads are
regular-file/64MiB bounded and check identity before/after; local file URI bytes
are decoded once. Static replacement changes invalidate the cache; slideshow XML
is still unsupported. `picture-opacity` and desktop icons remain documented
schema/legacy settings without a corresponding stock GNOME 51 Background control.
